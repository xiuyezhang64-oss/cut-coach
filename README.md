# cut-coach · 中文减脂精算教练

一个 Claude 技能（Skill）。它把"想要薄肌 / 下颌线 / 减肚子"这类目标，变成**按克计算的每日饮食 + 每周训练计划**，并且**自动建档记住你**。之后每天你只要告诉它吃了什么、练了什么，它会帮你算"今天还能吃多少"、告诉你外卖聚餐怎么吃、每两周按体重数据调整计划。

> 适合：坐办公室、时间不多、愿意用厨房秤称食物、想减脂同时保住肌肉的人。

## 它能做什么

| 功能 | 说明 |
|---|---|
| **个性化目标** | 根据性别、年龄、身高、体重、训练频率、有氧量，算出训练日 / 休息日分别吃多少热量、蛋白质、脂肪、碳水 |
| **落到具体菜单** | 换算成每顿吃几克肉、几克生米、几克油，支持"一锅出"批量备餐 |
| **今天还能吃多少** | 告诉它已经吃了什么，它算出剩下的额度，再换算成"几个手掌的肉、几个拳头的饭" |
| **外卖 / 聚餐指导** | 健身餐、麻辣烫、火锅、中餐、粉面怎么点、怎么吃 |
| **训练计划** | 每周 3 练或 4 练（上下肢分化），含加重规则、体态矫正动作 |
| **复盘与调整** | 读你的体重日志算两周趋势，按规则只调碳水；读训练日志给出下次重量 |
| **自动建档** | 数据存在你电脑上，换对话窗口也不会忘 |

## 安装

### 推荐：像项目一样用（最简单，适合朋友）

前提：装好 Claude 桌面版（Code 标签页）或 Claude Code，电脑上有 [Git](https://git-scm.com/downloads) 和 Python 3.8 以上。

1. **新建一个空文件夹**，比如 `D:\cut-coach`。在 Claude 里新建会话，文件夹选它。
2. **把下面这段话发给 Claude**：
   ```
   请把 GitHub 仓库 https://github.com/xiuyezhang64-oss/cut-coach 克隆到当前文件夹（直接放在当前文件夹里，不要再套一层子目录），然后按 CLAUDE.md 帮我做第一次配置。
   ```
3. Claude 会检查 Python、建好你的数据文件夹 `me/`，然后开始问你身高体重这些，做出你的计划。
4. 以后每次**新开会话说 `hello`**，就会出菜单：

   | # | 做什么 |
   |---|---|
   | 1 | 做计划 / 改计划 |
   | 2 | 安排今天（或明天）吃什么 |
   | 3 | 算还能吃多少 |
   | 4 | 记录：晨重 / 训练 |
   | 5 | 今天练什么 |
   | 6 | 外卖、聚餐、看食品标签 |
   | 7 | 两周复盘 |

   回个数字就开始。也可以不出菜单，直接说"今天晨重 71.2"、"中午吃了……还能吃多少"。
5. **作者更新了新版本**：跟 Claude 说"更新项目"，它只拉取、不会动你的数据。

> 你的数据都在 `me/` 文件夹里，只在你自己电脑上，不会上传。

### 方式二：作为插件安装（Claude Code）

在 Claude Code 对话框里输入：
```
/plugin marketplace add xiuyezhang64-oss/cut-coach
/plugin install cut-coach@cut-coach-marketplace
```

或者在终端里执行：
```bash
claude plugin marketplace add xiuyezhang64-oss/cut-coach
claude plugin install cut-coach@cut-coach-marketplace
```

装好后重启 Claude Code。

### 方式三：Claude 网页版 / App

1. **Settings → Capabilities**，打开 **Code execution and file creation**
2. **Customize → Plugins → Add → Add marketplace**，填 `xiuyezhang64-oss/cut-coach`，然后安装 `cut-coach`

> 网页版不能长期保存文件。每次方案有改动，Claude 会在回答末尾给一段**"存档卡"**。建议建一个 **Project**，把存档卡放进项目知识库；以后都在这个 Project 里聊。

### 方式四：手动安装

下载本仓库，把 `plugins/cut-coach/skills/cut-coach` 这个文件夹复制到：
- Windows：`C:\Users\<你的用户名>\.claude\skills\`
- macOS / Linux：`~/.claude/skills/`

然后重启 Claude Code。

## 快速开始

1. 准备一个**厨房秤**。
2. 项目模式说 `hello` 选 1；插件模式直接跟 Claude 说：
   ```
   帮我做一个减脂计划
   ```
3. 它会一项项问你：性别年龄、身高、**早上空腹体重**、大概体脂、目标和截止时间、每周能练几天、在健身房还是家里、有没有伤病、平时怎么吃、不吃什么。如实回答就行。
4. 它会给你：
   - 训练日 / 休息日分别吃多少
   - 一周训练安排和每个动作的组数次数
   - 调整规则和预期时间线
5. 同时在 `~/.cut-coach/` 建好你的档案。

## 日常怎么用

直接用大白话说就行，下面是一些例子：

**问今天怎么吃**
```
今天周三训练日，帮我安排一天的饮食，想吃牛肉和番茄炒蛋
```

**算还能吃多少**
```
今天周二休息日。早上 2 个蛋 + 1 盒奶，中午 200g 鸡胸 + 半碗饭 + 一盘青菜，晚上还能吃多少？
```

**备餐**
```
我周日要一次做 3 天的饭，用我常做的那套菜，告诉我买多少、怎么分
```

**外卖 / 聚餐**
```
晚上和朋友吃火锅，怎么吃不超？
帮我看看这个外卖怎么点（附截图）
```

**看食品标签**
```
这个虾仁能买吗？（附营养成分表截图）
```

**记录与复盘**
```
今天晨重 71.6kg
这是我今天的训练记录：卧推 40kg 8/8/7（剩1）……
这两周体重是这样的……要不要调热量？
```

**说话时注意三件事，它会算得更准：**
1. 说清楚**今天星期几、是训练日还是休息日**
2. 说清楚**是生重还是熟重、是一顿还是一锅的量**
3. 喝了奶茶、咖啡、吃了零食水果，也一起说

> 嫌太细就说"**给我个简单版**"，它会换成"手掌拳头法"；想精确就说"**按克来**"。

## 你的数据存在哪

项目模式下存在仓库里的 `me/` 文件夹（不上传）；插件模式下自动创建 `~/.cut-coach/`（Windows 上是 `C:\Users\<你的用户名>\.cut-coach\`）：

| 文件 | 内容 |
|---|---|
| `current.md` | **当前执行的方案**：每日目标、固定吃法、训练安排、下次重量、调整规则、待办 |
| `weight-log.md` | 每天的晨重和热量（只追加，不删改） |
| `lift-log.md` | 每次训练的动作、重量、次数（只追加，不删改） |
| `menus.md` | 你常做的菜单 |

- 这些文件只存在**你自己的电脑上**，不会上传到任何地方。
- 你可以随时打开看、自己改。
- 想改存放位置，设置环境变量 `CUT_COACH_HOME`。
- 生病、拉肚子这类异常日子，在体重日志备注里写"**排除**"，计算趋势时会跳过。

## 计算规则

| 项目 | 规则 |
|---|---|
| 热量 | 按公式估算每日消耗（误差约 ±200 kcal），默认缺口 15–25%，两周后用你的真实体重数据校准 |
| 蛋白质 | 每公斤体重 2.2–2.3g，每天落在一个区间内就算达标 |
| 脂肪 | 每公斤 0.75g，**不低于 40g** |
| 碳水 | 剩下的热量都给碳水，训练日比休息日多 |
| 调整 | **只调碳水**，每次 ±25g（约 33g 生米），看两周平均体重 |
| 误差 | 一天 ±100 kcal 算达标 |

调整规则：

| 两周平均每周体重变化 | 怎么调 |
|---|---|
| 掉体重的 0.5–1% | 不变 |
| 掉不到 0.3 kg | 每天碳水 −25g |
| 掉得太快，或主要动作连续 2 周做不动 | 每天碳水 +25g |

所有数字都由 `scripts/calc.py` 计算（纯 Python 标准库，无需安装依赖）。

## 常见问题

**Q：一定要称重吗？**
不一定。不想称就用"手掌拳头法"：每顿 2 个手掌大小的肉 + 1 个拳头的饭 + 随便吃的青菜。称重会更准。

**Q：米饭为什么按生米称？**
煮饭放多少水会影响熟饭重量，生米最准。别人做饭只能称熟的时候，它会帮你换算。

**Q：体重这周没掉？**
正常。肌酸刚开始吃、盐吃多了、生病，都会让体重短期波动。**看两周平均**，不看单日。

**Q：偶尔吃多了怎么办？**
让它过去，第二天照常吃。可以每周留一顿不计算的自由餐。

**Q：能只减肚子吗？**
不能。局部减脂已被研究否定，男生的肚子通常最后瘦。看腰围变化比看体重更直观。

**Q：蛋白粉、肌酸要吃吗？**
都不是必须的。肌酸每天 3–5g 性价比高；蛋白粉用来补吃不够的蛋白质，多喝一份就少吃一些肉。

**Q：买鱼虾要注意什么？**
看配料表。写了"水""磷酸盐"类保水剂的，蛋白质往往只有正常的一半、钠高很多。挑配料只有原料和盐、每 100g 蛋白质 15g 以上的。

## 更新与卸载

**更新**（第三方插件默认不自动更新）：
```bash
claude plugin marketplace update
claude plugin update cut-coach@cut-coach-marketplace
```

**卸载**：
```bash
claude plugin uninstall cut-coach@cut-coach-marketplace
```
卸载插件不会删除你的数据，`~/.cut-coach/` 需要的话手动删。
